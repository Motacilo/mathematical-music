# なんとなく作曲

作曲が苦手な人向けの Web アプリ。**雰囲気を選んで、候補を聴いて、気に入ったものを並べる**だけで、メロディ・コード・ベース・リズムの入った曲を作れます。

できた曲は **WAV**（ミックス音声）と **MIDI**（パートごとのマルチトラック）で書き出せます。サーバ不要・ブラウザだけで動きます。

## 起動方法

```bash
cd apps/web
npm install
npm run dev
```

ブラウザで表示された URL（通常 `http://localhost:5173`）を開きます。

ローカルでも GitHub Pages と同じパスで確認する場合:

```bash
npm run build
npm run preview
```

## 画面構成

タブ: **はじめる / メロディ / コード / ベース / リズム / 出力 / ショートBGM**（ほかに **ライブラリ**）

| タブ | 内容 |
|------|------|
| はじめる | 雰囲気・音色を選び、区間（イントロ〜後奏）を足すか、「おまかせで1曲作る」で一括生成 |
| メロディ | 分布 / 数列モードでフレーズ生成 → 譜面へ。1音ずつ音高調整 |
| コード | ランダム / 遷移確率 / 自由選択（定番進行）。弾き方: おまかせ（区間ごと）・同時押し・パルス・アルペジオ（響かせる／ピアノ風／16分／↑／↓／上下）・分解・アルベルティ風・ランダム |
| ベース | コード追従 / ランダム |
| リズム | Kick / Snare / HiHat のスタイル別パターン（4つ打ち・8ビート等） |
| 出力 | パート選択・音量・ミュート・ソロ・音色を設定し、WAV / マルチトラック MIDI を保存 |
| ショートBGM | ショート動画向け。長さ（10秒〜3分）・BPM・キー・雰囲気・パターン（A〜F、各1〜16小節）を選び、並び順の合計が目標小節数に合うと作成（WAV / MIDI 保存） |
| ライブラリ | お気に入りフレーズ・保存した譜面の呼び出し |

## 使い方

### かんたん（はじめるタブ）

1. **雰囲気**を選ぶ（明るい / 切ない / 疾走 / おだやか / かっこいい）。キー・BPM・音色が雰囲気に合わせて決まります
2. 曲を作る
   - **区間ごと**: 区間（イントロ・Aメロ・Bメロ・サビ・間奏・Cメロ・後奏）と小節数を選び「3つ出す」→ 聴いて「うしろに追加」。あとから区間ごとに差し替え可
   - **おまかせ**: 「いまの曲」右上の **おまかせで1曲作る** で、イントロ → A → B → サビ → 間奏 → A → B → サビ → C → サビ → 後奏 の1曲を一括生成

   はじめるタブで作るメロディについて:
   - 各小節のコードに合わせます（小節の頭・3拍目の4分以上・付点4分以上の音はコードの構成音に。コードと半音でぶつかる音は使わない）
   - リズムは1小節のリズム型の辞書から区間ごとにモチーフを選んで並べます。区間の役割・雰囲気・曲ごとの個性で、ゆったり〜細かいの傾きが変わります
   - 音域・跳躍の大きさ・旋律の山の形は曲ごとにランダムに決まります
   - コードの弾き方は区間ごとに雰囲気から選びます。イントロ・Cメロ・後奏などの静かな区間ではアルペジオになりやすくなります（コードタブの弾き方を「おまかせ（区間ごと）」以外にすると全小節がその弾き方になります）
   - Aメロ・Bメロ・サビ（8小節）は、4+4（40%）、2+2+4・4+2+2・繰り返しなし（各20%）のどれかで繰り返します。最後の小節は終わりのコードのままにするので、繰り返しても結びが変わります
3. **通しで聴く** で確認し、気になるところは各タブで直す
4. **出力** タブで WAV / MIDI を保存

### ショートBGM（ショートBGMタブ）

1. 雰囲気・長さ（秒）・BPM・キー・長調／短調を選ぶ。1小節は 240÷BPM 秒（4/4）で、目標小節数は「長さ÷1小節の秒数」
2. 割り切れないときは、少ない方（初期）と多い方の小節数から選ぶ
3. パターン数（1〜6）と各パターンの小節数（1〜16）を決め、ドラッグ＆ドロップ（◀▶✕ボタンでも可）で並べる。同じパターンは何度でも使える
4. 並び順の合計が目標と一致すると「BGMを作る」が押せる
5. 終わり方を選ぶ: **そのまま**（制限なし）/ **繰り返し**（最後をドミナントにして、最後の音を頭の音のすぐ隣へ。続けて流してもつながる）/ **伸ばす**（トニックで終え、1小節多く作って最後の音を前半だけ伸ばし、後半は休符）

はじめるタブの曲とは別に作られ、タブを切り替えても結果は残ります（ブラウザを閉じるまで）。

### 細かく（各レイヤタブ）

各タブとも「生成 → 候補を聴く → 譜面へ」の流れです。候補からは **ちょいアレンジ**（高さ違い・数音変更など）のバリエーションも出せます。キー・スケール・BPM は画面上部のプロジェクト設定で共通管理し、各タブの「プロジェクトキーに合わせる」（既定 ON）で連動します。

### メロディの生成モード

| モード | 内容 |
|--------|------|
| 分布 | 中心音を中央にした半音棒グラフ（キー外含む）。幅は ±4〜±18半音。プリセットに「完全ランダム」（全音均等）あり |
| 数列 | `n` を含む式（四則・べき乗）またはカンマ列。範囲は音名で指定。キー内ステップ／半音ステップ切替。範囲外はループ |

度数 `1` = トニック（キーの主音）。分布の棒はドラッグで確率変更できます。

## Cubase への取り込み

### MIDI（.mid）— 音符として再編集

1. Cubase でプロジェクトを開く
2. **ファイル → 読み込み → MIDI ファイル**（またはメディアベイからドラッグ）
3. Melody / Chords / Bass / Drums が別トラックで読み込まれるので、パートごとに編集

4/4・指定 BPM で書き出します。出力タブでチェックしたパートだけが入ります。

### WAV（.wav）— 音声として取り込み

1. Cubase のプロジェクトへ WAV をドラッグ＆ドロップ
2. オーディオイベントとして配置されます（音符編集は不可）

音量・ミュート・ソロの設定が反映されたミックスです。試聴・デモ用途向け。編集の本命は MIDI を使ってください。

## データの保存

作業中の曲・お気に入り・保存譜面はブラウザの **localStorage** に保存されます（サーバには送信しません）。ブラウザのデータを消すと失われます。アクセス解析に Google Analytics 4 を使用しています。
